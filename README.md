# 光伏储能微网购电优化

本仓库整理了论文《基于联合残差情景与动态价值调度的微网购电优化》的建模过程、Python 源程序、结果核验材料和[最终论文](paper.pdf)。研究按四问递进：确定性购电与储能调度、源荷预测误差下的日前计划与实时执行、日内新预报驱动的滚动调整，以及波动电价下的源荷价联合决策。

## 仓库结构

| 路径 | 内容 |
| --- | --- |
| `src/` | 四问的模型、预测、情景构造、实时执行、导出与验证程序 |
| `docs/q2_v2/`、`docs/q3_v2/`、`docs/q4_v1/` | 分问题的建模设计、参数选择、信息条件与结果分析 |
| `docs/论文正文.md`、`docs/论文终稿.tex` | 论文可编辑文本与 LaTeX 源文件 |

| `outputs/figures/` | 论文引用的主要矢量图 |
| `outputs/q2_v2/`、`outputs/q3_v2/`、`outputs/q4_v1/` | 年度汇总、消融比较和求解质量等中间结果 |
| `paper.pdf` | 最终论文 PDF |

## 建模路线

1. **问题一**：在已知负载、光伏和分时电价下，用线性规划联合决定购电量与储能充放电，日首与日末储电量均为 6000 kWh。
2. **问题二**：按同一历史日配对负载和光伏预测残差，构造完整日联合情景；日前优化共同购电计划，实时以近似未来成本指导储能动作。
3. **问题三**：在 0:00 制定原计划，于 6:00、12:00、18:00 使用新预报更新尚未执行的计划后缀，已执行时段保持锁定。
4. **问题四**：在未来实际电价不可提前获知的设定下，加入因果价格预测与源荷价联合情景，并比较日前锁定和日内滚动方案。

具体公式、信息边界与结算口径见论文和各问题的 `model_design.md` 等文档。问题四的同信息条件独立闭环消融资料位于 `outputs/q4_v1/ablation/same_info/`。

## 运行说明

推荐 Python 3.11。在仓库根目录安装依赖：

```bash
python -m pip install -r requirements.txt
```

原赛题附件及原始结果模板由赛题提供，本仓库未重复公开。复现时需按 `src/` 中的数据读取规则，将这些文件放在 `data/raw/`；再从仓库根目录运行相应问题的入口程序。主要入口包括 `src/solve_q1.py`、`src/q2_v2/run_stage4_policy.py`、`src/q3_v2/run_stage4.py` 和 `src/q4_v1/run_stage4.py`。全年求解可能耗时较长，建议先阅读对应的阶段与配置文档。仓库中保留的正式结果和核验数据可供直接检查，无须为阅读论文重新求解。

本仓库不提供赛题原始附件；仅凭仓库文件不能独立重跑完整实验。外部求解依赖及版本也应按实际运行环境核对。

## 结果概览

| 比较 | 全年实际费用 | 说明 |
| --- | ---: | --- |
| 问题二方案 | 13,763,928.208 元 | 较贪心执行对照降低 0.769% |
| 问题三日内调整 | 13,268,776.239 元 | 较禁止调整对照降低 4.525% |
| 问题 4-2 综合方案 | 14,540,193.850 元 | 波动电价环境 |
| 问题 4-3 综合方案 | 14,152,191.304 元 | 较问题 4-2 降低 2.668% |

问题 4-2 与 4-3 的配置和信息条件并非完全相同；日内调整权限的独立贡献见同信息条件消融材料。所有结果的定义和适用范围以论文及审计文档为准。
