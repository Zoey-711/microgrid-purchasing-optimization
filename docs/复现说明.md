# 数据与复现说明

本仓库公开源程序、已整理的部分中间结果、正式工作簿和论文，不包含竞赛提供的原始附件与空白模板。因此，仓库可以直接用于检查代码和已保存结果；完整重新求解需要先取得对应的赛题原始文件。

## 环境

建议 Python 3.11。在仓库根目录执行 `python -m pip install -r requirements.txt`。代码使用 Pyomo 和 HiGHS（`highspy`）；绘图及表格处理还使用 `numpy`、`pandas`、`matplotlib`、`seaborn` 和 `openpyxl`。依赖清单未锁定精确版本，若要严格重现数值，还需对照原求解环境、冻结配置和求解设置。

## 输入与入口

将竞赛提供的 `附件1.xlsx`、`附件2.xlsx`、后续附件及原始模板按代码中的文件名放入仓库根目录的 `data/raw/`。读取规则见 `src/data_io.py`、`src/q2_v2/data.py`、`src/q3_v2/forecasting.py` 和 `src/q4_v1/run_stage4.py`。不要把本仓库已有的正式结果工作簿当作空白输入模板。

| 问题 | 主要代码入口 | 建议先读 |
| --- | --- | --- |
| 一 | `src/solve_q1.py` | `src/data_io.py`、`src/model_storage.py` |
| 二 | `src/q2_v2/run_stage4_policy.py --policy main_dp50` | `docs/q2_v2/q2_v2_model_design.md`、阶段冻结记录 |
| 三 | `src/q3_v2/run_stage4.py` | `docs/q3_v2/q3_v2_model_design.md`、阶段冻结记录 |
| 四 | `src/q4_v1/run_stage4.py` | `docs/q4_v1/q4_v1_model_design.md`、`docs/q4_v1/q4_v1_stage3_freeze_record.md` |

这些是源码入口索引，不表示可以在缺少赛题附件、模板、阶段检查点或完整冻结配置时直接重跑全年。程序可能写入 `outputs/` 下的结果文件；运行前应先备份或在独立副本中复现，不要覆盖仓库中保留的正式工作簿。

## 已有证据的位置

- 正式提交结果：`outputs/tables/result1.xlsx` 至 `result4-3.xlsx`。
- 问题二、三、四的逐日、月度和求解质量摘要：`outputs/q2_v2/`、`outputs/q3_v2/`、`outputs/q4_v1/`。
- 问题四同信息条件消融：`outputs/q4_v1/ablation/same_info/final_paired_reuse_summary.json` 及同目录的逐日、逐月和求解质量文件。
- 最终文件哈希：`outputs/final_audit/final_result_hashes.txt`。

由于竞赛提交包大小限制，本仓库沿用支撑材料中的精简结果集合；部分可由源码和原始附件再生成的大型逐槽轨迹、检查点与运行日志没有收录。已有结果与完整论文结论的关系见各问题的审计文档。
