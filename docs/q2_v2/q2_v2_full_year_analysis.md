# 问题二 V2：阶段4全年影子评价分析

## 评价定位与固定配置

本文件报告阶段3在2025年1月开发期冻结的候选，2025-02-01至2025-12-31共334天的因果回放表现。它不是据全年结果重新选出的策略，也不构成理论全局最优性证明。

固定配置为：每日最多使用此前14个完整残差日构造历史联合残差情景，终端库存价值系数为0.4元/kWh，实时DP SOC网格为50 kWh；日前情景MILP单线程、随机种子0、时限45秒、请求相对gap为0.0001。终端库存价值仅影响日前优化，不从实际购电账单中扣除。

实际费用统一按

\[
C^{\mathrm{actual}}=\sum_{d,t}\pi_t p_{d,t}+\sum_{d,t}5\pi_t e_{d,t}
\]

复算。其中，计划购电量在每日0:00锁定，紧急购电只补足真实缺额，且不允许用于充电。

比较的两条独立跨日轨迹为：

- 主策略：历史联合情景MILP日前计划 + DP50近似未来价值实时执行器；
- 完整闭环对照：相同预测、场景数上限、终端价值、日前模型与求解配置，但实时执行器改为贪心规则。

二者各自从其合法的1月预热轨迹承接SOC，并分别跨日传递。因此，该比较同时包含实时执行差异及个别限时日前MILP incumbents 导致的计划差异。为单独识别执行器差异，另做“同日计划、同日初SOC”的日级配对消融，结果不与独立跨日比较混合。

|---|---:|---:|---:|

| 紧急购电费（元） | 916,569.077 | 1,023,019.543 | -106,450.466 |
| 实际总费用（元） | 13,763,928.208 | 13,870,589.590 | -106,661.382 |
| 紧急购电量（kWh） | 176,902.132 | 172,161.349 | 4,740.784 |
| 紧急购电加权平均单价（元/kWh） | 5.181221 | 5.942214 | -0.760993 |
| 最大单日紧急购电量（kWh） | 13,950.034 | 13,949.646 | 0.387 |
| 平均日末SOC（kWh） | 2,030.403 | 2,029.414 | 0.990 |
| 最小日末SOC（kWh） | 1,200.000 | 1,200.000 | 0.000 |
| 正式期末SOC（kWh） | 1,404.800 | 1,404.800 | 0.000 |
| 实际SOC范围（kWh） | [1,200, 10,800] | [1,200, 10,800] | — |

主策略的实际总费用较完整闭环贪心对照低106,661.382元，即低0.768975%。该差额主要来自紧急购电费用低106,450.466元；计划购电费差仅为210.916元。

同时，DP50的紧急购电总量反而高4,740.784 kWh，但其紧急购电加权平均单价低0.760993元/kWh。这说明在本次因果回放中，费用差不能用“DP减少了所有紧急购电量”解释；更符合数据的描述是：两种执行器的紧急缺额发生时段及相应电价不同。该现象需与逐槽电价区间统计一并解释，不应扩展为未经验证的普适结论。

独立跨日策略按日比较时，DP50实际费用较低88天、相同218天、较高28天。该日数不能简单视为纯执行器效果，因为两条轨迹会随着SOC和限时MILP incumbent逐日演化。

## 日级配对执行器消融

对每个正式日，固定主策略该日的计划购电量和日初SOC，只替换实时执行器，得到以下334日配对结果：

| 指标 | DP50执行 | 配对贪心执行 | DP50−配对贪心 |
|---|---:|---:|---:|
| 实际总费用（元） | 13,763,928.208 | 13,870,590.530 | -106,662.322 |
| 紧急购电费（元） | 916,569.077 | 1,023,231.399 | -106,662.322 |
| 紧急购电量（kWh） | 176,902.132 | 172,179.780 | 4,722.353 |
| DP费用较低/相同/较高天数 | 79 | 237 | 18 |

配对消融中，DP50同样以更高的紧急购电量对应更低的紧急购电费用。这为“执行器改变缺额时段及其电价权重”的描述提供了较强的受控证据；但DP近似未来价值来自历史联合情景，不代表它掌握当天未来实际负载或光伏，也不应称为在线全局最优控制。

| 可用incumbent天数 | 334 | 334 |

“认证最优”表示求解器在该日满足设定求解精度；限时可行解仍被保留并报告其gap，不称为精确最优解。日前MIP gap也不能直接当作全年实际费用差的误差界。

全年写后核验结果如下：

- 两条独立轨迹均为334日、每日至少144槽，正式期共48,096个槽/策略；
- 首个正式日主策略SOC与阶段3选定1月轨迹末端误差为0；两条独立轨迹跨日SOC误差均为0；
- 最大能量平衡残差为 \(4.55\times10^{-13}\) kWh，最大SOC状态转移残差不超过 \(5.46\times10^{-12}\) kWh；
- SOC边界、充放电功率、同时充放电、紧急购电同时充电的违规计数均为0；
- 日前计划与逐槽实际记录的锁定误差为0；负载/光伏预测历史来源与联合残差情景来源均严格早于决策日，违规计数为0；
- 所有45个受保护文件SHA-256均未变化，未创建或修改任何 `result2.xlsx`。

日级配对消融并非跨日策略，故其相邻日SOC不要求连续；它已核验每个配对日的日初SOC与主策略该日初SOC一致。该口径与独立跨日轨迹的跨日连续性检查分开处理。

## 局限与后续边界

1. 阶段3参数仅用1月开发期确定，全年结果仅用于固定候选的评价，不应根据这里的数值回改M、终端价值或DP网格。
2. 终端库存价值是跨日机会成本近似，未计入实际费用，也不能解释为售电收入或补贴。
3. DP使用历史联合情景路径价值的加权近似，而非严格多阶段随机DP；其优势或劣势应以实际因果回放账单为准。
4. 目前仍为影子评价结果。未经用户明确授权前，不生成、填写或替换官方 `result2.xlsx`。
