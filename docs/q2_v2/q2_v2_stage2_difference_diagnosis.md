# 问题二 V2 阶段2差异诊断

独立闭环的费用差同时包含跨日SOC差异及由此产生的次日计划差异，不能归因于DP执行器本身。逐日明细见 `q2_v2_stage2_independent_daily_diagnosis.csv`。

配对动作差定义为

\[\sum_t |(c_t^{DP}-b_t^{DP})-(c_t^{G}-b_t^{G})|.\]

累计充放电、转换损耗、弃能和日末SOC见 `q2_v2_stage2_paired_energy_diagnosis.csv`；动作差最大槽的候选分解见 `q2_v2_stage2_max_difference_action_candidates.csv`。

并列规则现固定为：主目标绝对差不超过 $10^{-8}$ 元时，优先最小化当槽充放电吞吐量；其余字段仅用于确定性排序。该规则不是折旧费，也未改变题面费用。

规则修订前后配对累计动作差分别为 29518.770412 和 29518.770412 kWh，变化 0.000000 kWh；配对费用差前后均为0元。由此可见阶段2的大动作差不是该并列次序造成，而主要来自近似未来价值在无紧急费用情况下允许多种跨期等价SOC路径。

## 相同计划、相同初态的能量统计

配对三日中，DP100累计充电52427.871 kWh、放电45436.576 kWh、转换损耗10291.296 kWh、弃能51145.119 kWh；贪心累计充电54458.267 kWh、放电45436.576 kWh、转换损耗10494.335 kWh、弃能49114.724 kWh。每日末SOC详见诊断CSV。

三日动作差最大值均出现在槽65（官方标签11:00）。以1月15日为例，该槽为富余状态：DP选择不充电，贪心充电833.333 kWh；两者“当前紧急费用+近似未来价值”均约为13211.020162元。所有候选在显示精度下价值相同，修订后的次级规则选择吞吐量为0的动作。候选完整分解保存在 `q2_v2_stage2_max_difference_action_candidates.csv`，实际SOC始终采用连续值并对网格价值作线性插值。
