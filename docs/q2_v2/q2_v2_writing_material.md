# 问题二 V2 论文写作素材

## 正式主策略名称

**历史联合残差情景—动态价值调度策略**。

本文提出历史联合残差情景—动态价值调度策略。日前阶段利用历史负载与光伏联合残差构造不确定净负荷情景，通过随机 MILP 确定统一计划购电量；实时阶段以历史情景后向递推得到的近似未来成本函数为依据，实施动态价值储能调度。本文后续简称其为“动态价值调度策略”。

代码/实验标识 `DP50` 仅表示实时执行器使用 50 kWh 的 SOC 离散网格；它是实现参数，不是方法名称，也不作为正文中的策略名称。

## 结果表述建议

在 2025-02-01 至 2025-12-31 的 334 天因果回放中，动态价值调度策略的实际总费用为 13,763,928.208 元，较贪心对照降低 0.769%。其计划购电费与对照接近，而紧急购电费用更低。该策略的紧急购电总量并未降低，反而略高；结合其较低的紧急购电加权平均单价，可将结果解释为紧急缺额发生时段及价格权重发生变化，而不能写作其减少了全部紧急购电需求。两种策略全年末 SOC 相同，故全年费用差不由末端库存透支造成。

## 模型限制

历史联合情景路径价值函数是基于过去残差日构造的近似未来成本，并不是当天未来实际负载和光伏的完美预知，也不是理论全局最优控制。终端库存价值只作为跨日机会成本近似，不计入实际支付费用。全年结果是固定参数的因果回放评价，不能据此反向调整开发期参数。
