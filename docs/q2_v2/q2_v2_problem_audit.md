## 2. 官方题意核对

官方总目标表述为：利用负载、光伏发电量和储能当前电量等数据，使微网供电满足负载，并“尽可能节省微网的购电费用”。

问题2明确规定：

> 若每天的电价相同，而小区负载和光伏发电功率随时间变化，且微网提供的电能不可低于小区负载，如果低于负载，需向外网紧急购电，其电价是交易时刻电价的5倍。除紧急购电费用外，其他时间段的购电费用均按计划购电量计算。请在每天0:00制定微网当天的计划购电策略。

附件5进一步要求：在 `result2.xlsx` 中保存2025-02-01至12月31日每天0:00制定的144槽计划购电量、指定时间段实际充放电量、0:00和24:00储电量，以及实际紧急购电事件。

由此得到的硬要求为：

| 类别 | 题面硬要求 |
|---|---|
| 决策时点 | 每日0:00制定并锁定当天计划购电量，问题2没有日内调整机制。 |
| 供电 | 实际供电不得低于实际负载。 |
| 紧急购电 | 真实缺额按当槽正常电价的5倍补足。 |
| 正常费用 | 除紧急购电外，各槽费用按已锁定计划购电量计算；计划未用完不退款。 |
| 数据 | 附件1只取144槽分时电价；附件2取实际负载和实际光伏。不得使用附件3、附件4或问题3信息。 |
| 储能 | 额定容量12000 kWh；运行SOC为1200—10800 kWh；最大充、放电功率5000 kW；双向效率0.9；2025-01-01 0:00初始SOC为6000 kWh。 |

问题2没有规定每日末SOC回到6000 kWh，也没有规定3600或6000 kWh日末硬保留线。新版不得把经济保留目标写成物理安全边界。

## 3. 费用与能量口径定稿

提示文本中公式因Markdown换行出现了减号或项目符号，但依据题面“紧急购电为5倍电价”及“总购电费用”的语义，实际支付费用必须是两项相加：

\[
C_{\mathrm{actual}}
=\sum_d\sum_{t=0}^{143}\pi_t p_{d,t}
+\sum_d\sum_{t=0}^{143}5\pi_t e_{d,t}.
\]

不得把紧急购电费写成负项。计划剩余、弃光、充放电均不产生收入；终端库存价值只允许进入日前优化目标，不计入上述实际支付费用。

代码使用每槽能量单位kWh。附件功率统一乘

\[
\Delta t=\frac16\ \mathrm h
\]

转为kWh。实际执行满足

\[
p_{d,t}+PV^{\mathrm{actual}}_{d,t}+b_{d,t}+e_{d,t}
=L^{\mathrm{actual}}_{d,t}+c_{d,t}+spill_{d,t},
\]

\[
E_{d,t+1}=E_{d,t}+0.9c_{d,t}-\frac{b_{d,t}}{0.9}.
\]

其中 \(c\) 是进入电池前的外部输入电量，\(b\) 是电池向微网输出的电量。任一槽必须满足充放电互斥；紧急购电只补当前缺额，不能用于主动充电。

| 事项 | 当前处理 | 性质 |
