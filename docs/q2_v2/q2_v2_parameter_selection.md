# 问题二 V2：1月开发期参数选择

## 1. 固定开发协议

共同评价期预先固定为2025年1月22日至31日，共10天；1月1日至21日只作冷启动和因果预热，不按紧急购电大小挑选日期。所有策略均从1月1日0:00的6000 kWh出发，1月1日采用零计划购电和贪心实际执行，随后按各自实际动作连续传递SOC，不在1月22日重置。

负载预测只读取此前35天内同星期几的同槽实际数据，无样本时回退至最近至多7天；光伏预测只读取最近至多7个已完成日。历史残差均由历史日当时可得的预测回放形成。初筛统一使用HiGHS单线程、随机种子0、8秒时限和0.2%目标gap；竞争候选再使用20秒/0.02%，最终评价段与选定策略使用45秒/0.01%。MIP gap只描述日前优化目标的界差，不作为实际闭环费用误差界。

## 3. 情景窗口比较

在初筛中暂有竞争力的 \(v=0.4\)+DP100上比较窗口：M14、M21、M30的实际费用分别为491672.780、503963.429、527751.238元。M21在评价期每天使用21条历史情景；M30的 \(M_{eff}\) 从1月22日的21逐日增加至1月31日的30，故不能声称整个评价期都充分验证了30日窗口。

M21、M30的8秒初筛最高日前gap分别达到4.62%和5.06%，证据精度弱于M14；但其实际费用分别高出约1.23万元和3.61万元，并未进入相近成本竞争组。因此保留M14，并在结论中将窗口选择证据标为“中等”，不能解释为所有较长窗口必然较差。

\(v=0.4\)低557.729元，且其期初和期末SOC均更高，因此该差额不是通过短期耗尽期末库存得到。但两种候选的评价期初SOC来自各自1月预热轨迹，不能把差额纯粹归因于单日终端项。终端价值仅影响优化，不从实际账单扣除。

为检查“评价期初库存由未计费预热免费提供”的潜在偏差，另对已有连续轨迹复算1月1—31日全部实际费用：精度复核下的 \(v=0,0.4,0.8\) 分别为2381147.770、2371385.460、2386137.698元，\(v=0.4\)仍最低；最终50 kWh配置为2370869.076元。该复算不是新的参数搜索，只是对既有候选的预热成本完整性检查，表明 \(v=0.4\)的选择并非仅由评价期初较高SOC造成。

## 5. SOC网格与解析算例

对三个竞争候选逐日固定同一计划和同一日初SOC比较100与50 kWh网格，三者排序不变；50 kWh网格对应的费用分别比100 kWh低181.743、224.197、426.967元。策略排序未改变，故没有触发25 kWh局部检查。

两槽确定性算例的精确解可直接核验：初始SOC 2055.5 kWh，可对外释放769.95 kWh；未来高价槽缺额675 kWh应优先全部满足，当前低价槽仅放电94.95 kWh并紧急购电405.05 kWh，精确费用为810.100元。50 kWh网格得到810.100元，与精确解一致；100 kWh网格得到900.100元，高90元。实际SOC在两种网格下均保持连续值，不吸附到网格。

## 6. 最终开发期回放与执行器消融

最终开发配置取M14、\(v=0.4\)元/kWh、50 kWh网格，使用45秒/0.01%的统一求解设置重新从1月1日连续回放。1月22—31日结果为：计划费483561.858元、紧急费7832.575元、实际总费用491394.433元、紧急购电1562.956 kWh；SOC由2540.013 kWh变为1781.855 kWh。10个评价日的日前MILP均达到请求gap，最高为0.00984%。

在每天固定相同计划和相同日初SOC的执行器消融中，DP50比贪心少支出2535.921元；两者紧急购电总量差仅为数值误差 \(6.9\times10^{-12}\) kWh。DP的收益来自把有限储能留给高价缺额，使同等总缺额在较低电价槽形成紧急购电，而不是减少紧急购电总量。该结果提供了DP时序价值的直接证据。

## 7. 冻结选择与证据强度

阶段3推荐并冻结：历史联合残差情景数上限M=14、终端库存价值0.4元/kWh、DP SOC网格50 kWh、主目标绝对差不超过 \(10^{-8}\) 元时优先最小吞吐量。推荐依据是：实际费用主指标最低、网格排序稳定、高精度竞争复核通过、同计划消融显示DP能降低按时段计价的紧急费用，且全部物理与信息检查通过。

证据强度评价为“中等”：共同开发期只有10天；M21和M30只做了有限时长初筛；正式评价尚未运行。后续2—12月只能评价本文件冻结的策略与预先确定的对照，不得依据全年成绩重新选择参数。
