# 问题二 V2 阶段4预注册协议

本协议在读取任何2025年2—12月策略评价结果前建立。唯一参数来源为 `outputs/q2_v2/stage3/q2_v2_frozen_strategy_config.json`。

## 固定方案

- 主策略：M=14、v=0.4元/kWh、联合情景MILP、DP 50 kWh网格；承接其1月31日日末实际SOC。
- 完整对照：相同预测、M、v、MILP和求解配置，改用贪心执行；从2025-01-01的6000 kWh按冻结冷启动规则补跑自身1月轨迹，再承接自身1月31日SOC。
- 配对消融：每日固定主策略的当日计划和日初SOC，分别运行DP与贪心；配对贪心不跨日，不构成第三条全年策略。
- 正式评价期：2025-02-01至12月31日，共334天。两条完整策略各自跨日传递SOC，不每日重置。

## 信息与情景

每日0:00只使用此前已经完成的实际负载、光伏及其因果回放残差。M=14表示每天滚动使用此前最近14个完整历史残差日，不重复使用固定的1月情景。计划生成后锁定；实际执行只读取当前槽真实负载、光伏、当前SOC和0:00形成的近似未来价值。

## 求解与异常规则

HiGHS单线程、种子0、时限45秒、相对gap 0.0001。到时限但存在通过约束检查的可行incumbent时继续使用并标记“限时可行”，不得称为精确最优解。当前没有预注册的无解后备计划；若某日没有可用解，运行器写出失败检查点后立即停止，不填零、不临时发明策略、不读取未来实际值。

## 评价口径

实际支付费用只含计划购电费和5倍当槽电价乘紧急购电量。终端库存价值只影响优化，不计入账单。预先规定输出年度、月度、日度、逐槽、求解日志、信息边界、配对消融、电价区间紧急购电量和全部物理验证。正式期结果不得用于回改阶段3参数。

本阶段仍不生成或修改任何 `result2.xlsx`。
