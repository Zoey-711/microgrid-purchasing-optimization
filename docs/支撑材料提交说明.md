# 支撑材料提交说明

本目录用于支撑论文《基于联合残差情景与动态价值调度的微网购电优化》的模型、结果和结论。赛题原始附件不重复打包；复现时将赛方提供的附件1—4及原始结果模板放入项目 `data/raw/` 下即可。

## 文件结构

| 路径 | 内容与用途 |
| --- | --- |
| `论文/` | 终稿 PDF 与 AI 工具使用详情 |
| `源程序/` | 全部自写 Python 源码、依赖清单与运行说明 |
| `配置与正式结果/` | 冻结配置、五份正式结果 Excel 与最终哈希 |
| `结果核验/问题二` | 年度逐日、月度、方案对照、求解质量、信息边界及物理核验材料 |
| `结果核验/问题三` | 年度逐日、月度、计划版本摘要、方案对照、求解质量、信息边界及物理核验材料 |
| `结果核验/问题四` | 年度逐日、月度、费用构成、求解质量、价格信息边界及物理核验材料 |
| `结果核验/问题四同信息消融` | 锁定与滚动方案的日级、月级、求解质量、继承等价性与配对验证材料 |
| `论文图表/` | 正文引用的矢量 PDF 图表 |
| `审计说明/` | 终稿一致性与问题四论文修改审计 |

## 运行环境

使用 Python 3.11；在项目根目录执行：

```text
python -m pip install -r requirements.txt
```

之后，按 `源程序/README.md` 的目录约定放置赛题附件，并从项目根目录运行相应问题的正式入口。求解依赖 Pyomo 与 HiGHS（`highspy`）；原始附件、冻结配置和正式结果均应保持只读。

## 说明

- 所有模型源码在论文附录 C.2 中以代码 C-1—C-34 完整列出；本支撑材料同时提供相同 `.py` 文件以便实际运行。
- 为控制提交体积，未重复打包可由源码与赛题原始附件再生成的逐槽超大 CSV、检查点和控制台日志；论文结论所需的逐日、逐月、年度比较、求解质量、信息边界、物理核验和正式 Excel 均已保留。
- 问题四同信息条件独立闭环消融的 rolling 分支只读复用正式 Q4-3 冻结轨迹；其等价性审查材料随包提供。
