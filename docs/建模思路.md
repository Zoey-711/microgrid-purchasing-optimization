# 四问建模思路

微网必须提前申报购电计划，但负载、光伏出力和电价信息会在运行过程中逐步揭示。四问共用储能容量、功率、效率、供需平衡和储电量递推约束；变化的是作出决策时能看到什么，以及是否允许修改尚未执行的计划。

## 问题一：先建立物理与费用基准

当负载、光伏和分时电价已知时，核心权衡是把多少电量从低价时段转移到高价时段。模型以购电费用最小为目标，用 144 个十分钟槽和跨槽储电量递推连接购电、充电和放电。日首与日末储电量相同，保证节费并非来自耗尽库存。此问采用连续线性规划；结果与导出程序见 `src/solve_q1.py`。

## 问题二：提前申报与真实供需之间的偏差

过少申报会引起五倍电价的紧急购电，过多申报又可能造成转换损耗或富余弃能。逐槽独立抽取误差会破坏一天内的变化形态，因此按同一历史日配对负载与光伏预测残差，生成完整日联合情景。日前模型在所有情景之间共享购电计划，以情景补救变量衡量计划风险；实际执行只使用当前可见的供需和储电量，由历史情景近似出的未来成本指导动作。情景内补救轨迹不直接当成真实运行指令。设计见 `docs/q2_v2/q2_v2_model_design.md`，主要代码在 `src/q2_v2/`。

## 问题三：让新预报真正影响未执行计划

如果获得 6:00、12:00、18:00 的新预报却仍执行原全天计划，新增信息只能改变储能动作，不能修正合同购电量。因此在 0:00 制定原计划，之后只优化尚未执行的后缀，已执行槽锁定。结算以每槽最终生效量相对 0:00 原计划计算一次；这项多次调整结算口径是明确列出的建模假设。设计见 `docs/q3_v2/q3_v2_model_design.md`，滚动模型见 `src/q3_v2/rolling_milp.py`。

## 问题四：再加入未来电价的不确定性

固定分时电价改为波动电价后，日前决策不能提前使用未来实际价格。价格预测只使用决策时点前已实现的数据；价格残差与同一历史日的源荷残差联合构造情景。正式结果分别给出日前锁定的 4-2 综合方案和日内滚动的 4-3 综合方案。两者还有情景规模、光伏信息等差异，因此正式费用差体现综合方案差异。为单独识别日内计划调整的作用，另做同信息条件独立闭环消融，结果和继承等价性材料位于 `outputs/q4_v1/ablation/same_info/`。

## 评价口径

- 正式全年评价为 2025-02-01 至 2025-12-31，共 334 天、48,096 个十分钟槽；各方案的储电量按实际执行结果连续跨日传递。
- 实际账单由合同或计划结算费用与紧急购电费用构成。优化目标中的终端储电量价值不计入账单。
- 问题二、三使用固定分时电价，问题四使用波动电价；跨问题绝对费用不能直接用于单一机制的因果归因。
- 参数选择、信息权限、求解状态与物理验证的细节以对应的冻结记录、结果审计和论文正文为准。
