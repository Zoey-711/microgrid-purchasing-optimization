# 问题四 V1：继承关系审计

问题四是对问题2和问题3的变动电价重算，不是对前三问参数的直接搬运。继承的是经验证的物理、行序和审计框架；与价格信息、预测、场景规模和库存价值有关的部分必须重新开发。

| 模块 | 结论 | 理由 |
|---|---|---|
| 问题1确定性储能物理模型 | 直接继承 | 容量、效率、功率、SOC边界和10分钟能量换算均由附件1给定，与电价变化无关。 |
| 问题2V2历史联合残差情景 | 修改后继承 | 负载—光伏同日残差配对与日内相关性保留；但预测器、情景数和可能的价格场景须在问题4开发期重新选择。 |
| 问题2V2动态价值储能执行 | 修改后继承 | 可复用“历史路径价值平均+连续SOC插值”的因果控制结构；未来价值必须纳入当时可得的价格信息，网格和值函数参数不得照搬。 |
| 问题3V2四时点光伏预报解析 | 问题4-3直接继承 | 附件3相同；整点预报、已发布左锚点与线性插值映射可先作为候选并重新审计。问题4-2不适用日内预报更新。 |
| 问题3V2计划版本锁定 | 问题4-3直接继承 | 0:00、6:00、12:00、18:00仅修改未执行后缀；问题4-2只有0:00计划，天然无日内版本。 |
| 问题3V2调整购电结算 | 修改后继承 | 最终生效量相对原计划单次结算可避免重复收费；但波动价下价格时点未被题面明确，必须重新写为问题4假设。 |
| SOC连续跨日传递 | 直接继承 | 题面只给初始SOC，未要求每日恢复6000 kWh。 |
| 紧急购电只补缺、不得主动充电 | 直接继承 | 由供需平衡和紧急购电定义决定，仍须逐槽检查。 |
| 信息边界检查与费用复算 | 修改后继承 | 保留负载/PV/预报/版本审计，并新增价格发布、价格预测与实际结算的可用时间审计。 |
| 模板写入及逐单元格复核 | 直接继承 | `result4-2`与问题2模板、`result4-3`与问题3模板的字节哈希分别相同；未来仍应复制原始模板后写入并回读核验。 |

下列旧项**不可直接继承为问题4配置**：问题2V2的\(M=14\)、\(v=0.4\)元/kWh、50 kWh网格；问题3V2的100 kWh网格、同星期几负载预测、全部日内更新及其合同结算解释；任何旧策略对照和旧全年结果。它们至多是开发期候选或工程参考，不能作为题面事实或预设最优。
