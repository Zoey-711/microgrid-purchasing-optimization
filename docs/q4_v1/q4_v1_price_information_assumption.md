# 问题四 V1：价格信息可得性假设（阶段2冻结）

> 本文件是为处理题面未说明电价发布时间而设置的透明建模假设，不是对官方题意的转述。

附件4的实际波动电价 \(\pi^{\rm actual}_{d,t}\) 仅在槽 \(t\) 开始时可知。0:00、6:00、12:00、18:00决策时，模型只能读取此前已经完成槽位的实际价格；不能读取当天未来槽的附件4实际价格。未来槽价格由历史已完成日期的槽位点预测及其完整日内残差轨迹构造；当前槽实际价格可用于实时动作比较。附件4未来实际价格仅在槽执行后的结算与回放评价中使用。

阶段2固定的简单价格预测器为：优先取此前35日内同星期几的同槽平均；若该集合为空，则取此前最多7个完整日的同槽平均；仍无样本时取全零。每一日的价格残差定义为 \(\epsilon^\pi_{i,t}=\pi^{\rm actual}_{i,t}-\widehat\pi_{i,t}\)，其中\(\widehat\pi_{i,t}\)必须按日\(i\)当时的历史数据回放得到。场景库按完整历史日保存144槽残差轨迹，不拆散抽样。价格预测下限为0；非正预测值规范为0，实际附件4价格不改写。

每条预测记录保存决策时间、目标槽、最大历史日期和来源日期；若最大历史日期不早于决策日期即判为泄漏。
