## 2. 题面明确的物理与费用事实

附件1给出：储能额定容量12000 kWh，充、放电最大功率均5000 kW，2025-01-01 0:00初始SOC为6000 kWh，SOC安全范围1200--10800 kWh，充、放电效率均为0.9。全部功率型输入均应先按 \(\Delta t=1/6\) h转换为槽电量（kWh）。

沿用题面已明确的供需物理口径，令 \(p\) 为计划/生效购电量、\(g\) 为光伏、\(L\) 为负载、\(b\) 为电池对外放电量、\(c\) 为电池充电前外部输入量、\(e\) 为紧急购电量、\(w\) 为弃能量，则

\[
p_{d,t}+g_{d,t}+b_{d,t}+e_{d,t}=L_{d,t}+c_{d,t}+w_{d,t}.
\]

实际SOC按 \(E_{d,t+1}=E_{d,t}+0.9c_{d,t}-b_{d,t}/0.9\) 连续递推。紧急购电只补足当前真实缺额，不得被用于主动充电；这一条既符合供需平衡，也应在执行审计中逐槽核验。

## 3. 信息边界：已确认与待解释

1. 附件2是全年实际负载与实际光伏，属于回放评价中的实现值，不能被提前作为当天未来信息。
2. 附件3每个日期提供0:00、6:00、12:00、18:00四个、每次24小时的光伏功率预报；问题4-3可以继承问题3的发布版信息结构。
3. 附件4提供2025年每日144槽的波动电价实际序列，单位元/kWh。
4. 已执行槽位不可被后续版本追溯修改，是问题3信息结构的必要锁定规则；问题4-3仍应保留。

## 4. 与前三问的递进关系

问题1解决固定已知负荷、光伏和价格下的一日确定性储能调度；问题2加入每日0:00信息不足与紧急购电；问题3进一步加入附件3多时点光伏预报与购电版本调整。问题4并不自动复制此前参数，而是在上述两种信息结构中引入未明确提前可见的变动电价，新增的核心审计对象是**价格可得性、价格预测误差和按实际价格的费用复算**。
