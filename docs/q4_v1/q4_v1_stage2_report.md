# 问题四 V1 阶段2：价格口径与三日最小因果闭环

## 范围与固定工程设置

本阶段仅运行2025-01-15--2025-01-17三个连续日，日初SOC为独立闭环测试初始化6000 kWh；16日、17日均继承主轨迹前一日实际日末SOC。该初态不是1月1日起连续运行所得状态。未进行参数搜索、1月开发期、全年评价或任何模板写入。

为验证链路，预先固定一个简单候选：价格/负载优先“此前35日同星期几同槽均值”、无同星期几时回退此前最多7个完整日；PV在4-2用历史同槽均值，在4-3使用附件3当前发布版本的已发布预报左锚点分段线性插值；\(M=7\)，终端库存价值\(v=0\)元/kWh，价值网格200 kWh，MILP时限30 s、相对gap \(10^{-4}\)、单线程种子0。这些只是闭环测试设置，均未冻结为问题四正式参数。

## 已冻结的阶段2假设

价格信息假设见 `q4_v1_price_information_assumption.md`：附件4实际价格仅在目标槽开始时可知；未来实际价格不得进入0:00、6:00、12:00、18:00决策，而仅用于槽后结算。每日历史价格残差以该日当时的因果点预测为基准、按完整日轨迹保存。

变动价调整结算见 `q4_v1_variable_price_settlement_assumption.md`。问题4-3以最终生效量\(z\)相对0:00原计划\(p\)一次结算：\(z=p+\delta^+-\delta^-\)，\(C^{contract}=\pi^{actual}p+1.5\pi^{actual}\delta^+-0.5\pi^{actual}\delta^-\)，并另计\(C^{emergency}=5\pi^{actual}e\)。该结算解释和“按发布时点价格结算”的备选解释均不是题面已确认规则；后者未进入本阶段主模型。

## 人工结算测试

11个程序化算例均与独立手算一致：无调整100元；上调100至120为130元；下调至80为90元；中间版本80后最终110为115元；中间120后最终80为90元；最终回到100为100元；下调至80且紧急购电10 kWh为140元；原计划100、最终80时，价格0.4/1.2元/kWh分别为36/108元。最终生效量相同的不同中间版本均只计一次。\(-5\times10^{-7}\) kWh按\(10^{-6}\) kWh容差规范为0；正常正值保持不变。

## 求解与验证

4-2完成3次MILP，累计求解9.950 s，均为`optimal`，最大报告gap \(8.91\times10^{-8}\)。4-3允许调整完成12次、禁止调整完成3次，均为`optimal`；累计求解时间分别12.308 s、5.818 s。没有限时可行解或无可行解。

四条432槽轨迹的价格信息泄漏、SOC越界、功率越界、同时充放电、紧急购电同时充电及实质负数均为0。最大供需平衡残差分别不超过\(2.274\times10^{-13}\) kWh，最大SOC递推残差\(3.638\times10^{-12}\) kWh；主4-2与两条4-3独立轨迹跨日SOC残差为0。4-2贪心为“同计划、同日初SOC”的逐日条件配对，故不适用其跨日连续性检查。合同费用及紧急费用的逐槽独立复算误差不超过\(6.822\times10^{-13}\)元。

全部输入预测记录保存于 `q4_v1_price_information_inputs.csv`；各记录的价格历史来源均早于决策日。已执行计划后缀锁定误差为0。
