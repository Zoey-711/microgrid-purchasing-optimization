# 问题四图题与图注

**图4-1 代表日波动电价预测与储能响应。** 代表日按全年问题4-3轨迹中“高价紧急购电费用最大日”这一预先固定规则选取，为 2025-07-02。图(a)中的0:00价格预测、情景带和中位数均按冻结的最近14个完整历史日同槽均值及历史残差轨迹构造；未来真实电价未进入该日任何决策。实际价格仅在当前槽执行及事后结算时使用。为避免把每槽购电能量与储能功率强行置于同一量纲，图(b)、(c)分别展示购电和储能动作；图(d)给出连续SOC及物理安全边界。

**图4-2 波动电价下问题4-2与问题4-3的全年结果比较。** 图(a)以实际结算费用分解全年账单，图(b)比较实际紧急购电量，图(c)按未舍入月度账单差累计问题4-3相对问题4-2的费用节省，图(d)给出月末SOC。两分支的场景数、光伏信息来源和计划更新机制不同，因此图中差异是综合方案差异，不能完全归因于单一日内调整机制。期末SOC分别为 10279.388 和 10225.682 kWh，费用差并非由期末库存透支造成。
