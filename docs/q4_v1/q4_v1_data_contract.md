# 问题四 V1：数据契约与模板映射

## 1. 统一索引与单位

- 日期 \(d\)：2025-01-01至2025-12-31；正式模板输出为2025-02-01至2025-12-31。
- 槽位 \(t=0,\ldots,143\)：官方行序；SOC状态为 \(E_{d,0},\ldots,E_{d,144}\)。
- 槽宽：\(\Delta t=10\) min=\(1/6\) h。
- 附件2、附件3功率字段为kW，建模/模板中的每槽调度量为kWh：\(x^{\rm kWh}=x^{\rm kW}/6\)。
- 附件4为元/kWh；费用以元计算。
- 不因表头如“0:10-0:20”自行平移索引；读取、计算、写入始终按官方列的左至右顺序一一对应。

## 4. 数据质量与未来信息检查规则

下一阶段每个决策记录必须保存：决策日期/槽位、输入来源、目标日期/槽、发布或观测可用时刻、是否早于决策时刻。任何负荷、光伏实际值、价格实际值、预报版本或历史残差日期晚于可用边界均计为信息泄漏。缺失、重复日期、非144槽、NaN、非数值价格、模板日期错位均为硬失败；不得用未来值补齐。
