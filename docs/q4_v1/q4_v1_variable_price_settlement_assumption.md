# 问题四 V1：变动电价结算假设（阶段2冻结）

> 题面未明确变动电价下多次调整的计价时点；以下是本阶段的主建模解释，不能写成题面明确规则。

令 \(p_{d,t}\) 是0:00原计划购电量，\(z_{d,t}\) 是槽执行前最后一个生效版本，\(e_{d,t}\) 是实际紧急购电量，\(\pi^{\rm actual}_{d,t}\) 是附件4目标槽实际价格。定义

\[
\delta^+_{d,t}=\max(z_{d,t}-p_{d,t},0),\qquad
\delta^-_{d,t}=\max(p_{d,t}-z_{d,t},0),\qquad
z_{d,t}=p_{d,t}+\delta^+_{d,t}-\delta^-_{d,t}.
\]

问题4-3每槽合同费用和紧急费用采用

\[
C^{\rm contract}_{d,t}=\pi^{\rm actual}_{d,t}p_{d,t}+1.5\pi^{\rm actual}_{d,t}\delta^+_{d,t}-0.5\pi^{\rm actual}_{d,t}\delta^-_{d,t},
\quad C^{\rm emergency}_{d,t}=5\pi^{\rm actual}_{d,t}e_{d,t}.
\]

每槽只相对0:00原计划结算一次；中间版本不累计收费。决策目标使用价格预测，事后账单使用目标槽实际价格。终端库存价值若被用于优化，仅为机会成本近似，绝不从实际账单抵扣。

备选敏感性解释为“按调整发布时间价格结算”；本阶段不混入主模型或结果。
