# 问题三 V2 最终结果审查

正式策略为**多时点预报更新—滚动购电调整与动态价值储能调度策略**。冻结 A 策略由逐槽源数据独立汇总：合同费用 13152259.342 元，紧急购电费用 116516.897 元，实际总费用 13268776.239 元，紧急购电量 29540.082 kWh，期末 SOC 1462.576 kWh。

相对禁止日内调整的 B 策略，A 的合同费用增加 84110.481 元，紧急购电费用减少 713050.234 元，实际总费用减少 628939.753 元（4.525%），紧急购电量减少 150478.078 kWh（83.590%）；A 期末 SOC 高 62.988 kWh。

上述结果为固定开发期参数下的因果回放，不主张理论全局最优。终端库存价值仅服务于优化，未从实际账单扣除。
