# 问题三 V2 阶段2差异诊断

## 1. 条件配对比较口径

阶段2比较固定主策略已经生成的全部计划版本，并令动态价值执行器与贪心执行器在每天使用相同日初 SOC。动作差定义为

\[
D_a=\sum_{d,t}\left(\left|c^{\mathrm{DV}}_{d,t}-c^{\mathrm{G}}_{d,t}\right|+
\left|b^{\mathrm{DV}}_{d,t}-b^{\mathrm{G}}_{d,t}\right|\right).
\]

三日共有60个槽位的动作不同，\(D_a=8295.356\ \mathrm{kWh}\)，最大槽后 SOC 差为2013.723 kWh。两执行器三日累计充电、放电、弃能、紧急购电量、紧急购电费及每天日末 SOC 最终相同，因此三日实际总费用差为0元。该结果只说明在固定主策略计划版本下，两种执行器改变了日内动作时序，但三日样本没有提供动态价值执行器经济优势的证据；它不是两套独立跨日闭环策略的比较。

## 2. 前两日较高日末 SOC 的来源

2025-01-15 从独立测试初值6000 kWh出发，累计充电25601.887 kWh、放电16417.528 kWh，按效率折算后的 SOC 净增量为4800 kWh，日末达到10800 kWh。充电电量对应的加权平均电价约0.570元/kWh，放电电量对应约1.118元/kWh。2025-01-16从10800 kWh出发，累计充电19215.219 kWh、放电16270.576 kWh，日末为10015.279 kWh。

这些高日末状态是滚动计划、当日供需富余、分时电价与测试终端价值共同作用下的闭环结果，并非题面规定的日末硬约束，也不能单独归因于某一个因素。阶段2的1月15日6000 kWh只是独立功能测试初始化，未被直接用作阶段3正式开发期的状态。

## 3. 并列动作规则与数值检查

并列最优动作采用冻结的确定性次级规则：在主目标最优容差内，优先减少储能吞吐量，再按固定元组顺序选择。该规则不向题面账单加入电池折旧费。50 kWh与100 kWh网格仅用于未来价值插值，实际 SOC 始终按连续物理方程递推。阶段3新增的两槽确定性算例给出可手算精确费用150元，两个网格均复现“低价时保留、高价时释放”的精确动作和费用；非网格 SOC 在无动作时保持原连续值。
