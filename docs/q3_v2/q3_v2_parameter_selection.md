# 问题三 V2：1月开发期参数选择

## 1. 共同开发协议

- 冷启动：2025-01-01 0:00，SOC为6000 kWh；当天计划购电量置零，仅用于初始化历史缓冲区和状态。
- 预热期：2025-01-02至01-21，各候选在自身因果闭环内连续传递实际 SOC。
- 共同评价期：2025-01-22至01-31，共10天；不按紧急购电大小选择日期，不在评价期开始时重置 SOC。
- 每个决策只使用当时已发布的附件3光伏预报、决策日前的历史负载与同版本历史联合残差。标称情景数不足时使用真实 \(M_{\mathrm{eff}}\)，不复制样本、不使用未来日期。
- 评价以实际合同结算费与5倍电价紧急购电费之和为主；预测 MAE、紧急购电量、库存状态、计算时间和求解质量作为辅助指标。终端库存价值不计入真实账单。

## 3. 选择依据

### 3.1 负载预测器

同星期几预测器的负载 MAE 为20.009 kWh/槽，EWMA候选为81.588 kWh/槽；在相同 \(M=14,v=0.4\) 下，前者实际费用低118058.372元。50 kWh网格交叉检查保持相同排序，因此选择“过去35天同星期几均值、样本不足时回退最近7天，并使用最近12个已完成槽偏差校正”的负载预测器。

### 3.2 联合情景数

在固定预测器、\(v=0.4\)和100 kWh网格下，\(M=14\)费用分别比\(M=7\)和\(M=21\)低681.626元和7168.582元。\(M=7\)的紧急购电量为241.098 kWh，明显高于\(M=14\)的10.289 kWh；\(M=21\)在共同评价期有7次限时可行解，最大相对 gap 为0.001256，计算成本也最高。因此冻结 \(M=14\)。这里的14表示每日滚动使用此前最多14个完整历史联合残差日，并非永久使用同一批情景。

### 3.3 终端库存价值

\(v=0\)的实际费用比\(v=0.4\)高1046.868元，紧急购电量也更高；\(v=0.8\)把评价期初、期末 SOC 均推至10800 kWh，实际费用反而高1463.347元，表现为过度保留。开发期选择 \(v=0.4\ \mathrm{元/kWh}\)。该量仅近似跨日库存机会成本，不是实际收入。由于不同候选的预热轨迹与评价期初库存不同，关于 \(v\) 的证据强度为中等，不能声称其理论最优。

### 3.4 SOC价值网格

100 kWh与50 kWh网格的紧急购电量和评价期末 SOC 相同；100 kWh网格实际费用低350.360元，动作L1差为4648.250 kWh，最大槽后SOC差634.909 kWh。网格加密没有改变候选排序，也没有改善实际费用；两槽可手算算例在两种网格下均得到精确动作和150元费用。因此采用计算更简洁的100 kWh网格。实际 SOC 不离散化，网格只用于近似未来价值插值。

## 4. 对照与消融

独立闭环“不调整购电”对照费用为490956.203元、紧急购电量1115.606 kWh；全部更新策略费用低2237.178元、紧急购电量低1105.317 kWh。两者使用相同信息访问规则和执行器，但各自在预热期与评价期递推自身 SOC；评价期初 SOC 分别为2566.433与2831.771 kWh，故该差额评价的是完整调整机制，而非严格日级配对效应。

固定主策略计划版本与同日初SOC的条件消融中，动态价值与贪心执行器费用均为488719.024元，紧急购电量均为10.289 kWh，每日日末SOC亦一致；但有36个动作不同槽，动作L1差3541.808 kWh。故本开发窗口支持日内购电调整的作用，但对动态价值执行器的独立经济优势辨识不足。后续正式评价必须保留这一负结果，不得预先宣称动态价值执行器优于贪心。

## 5. 冻结候选与证据强弱

阶段4的预先固定主候选为：同星期几负载预测、历史联合残差情景数\(M=14\)、终端库存价值\(v=0.4\)元/kWh、100 kWh价值网格，允许0:00、6:00、12:00、18:00四个版本更新，并采用历史路径价值平均形成的动态价值执行器。该执行器被保留为待正式期评价的预承诺候选，而不是因为1月消融已经证明其优越。

证据判断：预测器选择证据较强；\(M\)选择证据中等；\(v\)选择受库存路径差异影响，证据中等；50/100 kWh网格选择证据中等；动态价值执行器相对贪心的经济优势证据较弱。阶段4只能评价该冻结配置，不得按2—12月结果反向改参。
