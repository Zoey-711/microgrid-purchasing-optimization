# 问题三 V2 阶段 3：一月开发协议（运行前固定）

## 1. 数据与评价边界

- 冷启动日：2025-01-01，日初 SOC=6000 kWh；因无历史残差场景，当日原计划固定为0，实时按当前实际供需执行贪心充放电与紧急购电，仅用于初始化历史库和 SOC。为使1月2日起能够形成第一条真实历史残差，另保存1月1日当时可得的冷启动预测版本：负载预测固定为0，光伏使用当时已经发布的附件3版本；该日不参与评价。
- 因果预热：2025-01-02 至 2025-01-21。每个候选从相同冷启动状态独立运行，并按自身实际动作连续传递 SOC。
- 共同评价期：2025-01-22 至 2025-01-31，共10天；评价期开始时不得重置 SOC。
- 每日历史预测和残差库只允许使用当时已经完成的日期；历史不足时使用实际 \(M_{\rm eff}\)，重新归一化权重，不复制样本。
- 本阶段禁止读取2025年2—12月结果进行选择，不运行全年，不生成或修改 `result3.xlsx`。

## 2. 运行前固定的候选与顺序

为避免大规模笛卡尔积，按下列顺序筛选；每一步均以共同评价期实际合同结算费与紧急购电费之和为主指标，以物理可行、信息因果为前提。

1. **负载预测器筛选**：固定 \(M=14,v=0.4\) 元/kWh、网格100 kWh，比较：
   - `ewma14_bias12`：最近14个完整日指数加权同槽预测，半衰期7天；更新时用最近12个已完成槽残差中位数校正；
   - `weekday35_bias12`：近35天同星期同槽均值，样本不足时回退到最近7个完整日；更新时使用同样的12槽因果偏差校正。
2. **情景数筛选**：使用第1步入围预测器，固定 \(v=0.4\)、网格100 kWh，比较 \(M\in\{7,14,21\}\)。
3. **终端价值筛选**：使用入围预测器和 \(M\)，固定网格100 kWh，比较 \(v\in\{0,0.4,0.8\}\) 元/kWh。终端价值不计入实际账单。
4. **交叉补点**：额外评价“另一负载预测器 + 当前入围 \(M,v\)”以及“次优 \(M\) + 次优 \(v\)”；用于检查分步筛选遗漏的主要交互，不据此扩展全组合搜索。
5. **网格复核**：对入围组合比较50与100 kWh；实际 SOC 始终保持连续，网格只用于近似未来价值。

重复参数组合只运行一次。预计约9条全部更新独立闭环候选。每条候选从1月1日开始独立递推；1月2—31日每天最多4次MILP，约120次MILP，因此主体预计不超过1080次MILP。

## 3. 对照协议

### 3.1 独立闭环不调整对照

使用最终入围预测器、\(M,v\) 和网格，从相同2025-01-01初态独立运行。每日0:00计划固定不变；6:00、12:00、18:00仍可读取同一已发布预报并重建固定计划后缀的未来价值，但不调整购电量。其SOC按自身动作跨日传递。

### 3.2 条件执行器消融

固定入围主策略的全部计划版本轨迹，并令贪心与动态价值在每天使用相同的主策略日初SOC。贪心不重新优化购电计划；该实验只隔离给定计划轨迹下的执行器差异，不构成第二条独立跨日策略。

## 4. 选择规则

1. 信息边界、能量平衡、SOC、功率、互斥、结算复算、版本锁定全部通过；
2. 共同评价期实际总费用最低为主标准；预测MAE只作解释；
3. 报告紧急购电电价分布、终端SOC和吞吐量，避免把短期库存耗尽包装为稳定收益；
4. 若费用差小于求解精度或网格敏感性，优先选更简单、计算更稳定的配置；
5. 动态价值没有稳定经济优势时，允许冻结贪心或更简单执行器，如实保留负结果。

## 5. 计算预算

阶段2实测12次MILP总求解时间约30.5秒，平均2.542秒，最长5.805秒。按每候选约120次MILP估计，单候选约3—6分钟；约9条主候选、1条不调整对照及条件消融预计约35—75分钟。该预算还包括价值函数和文件写入开销，实际运行以逐次日志为准；不会以45秒时限乘以调用数作为唯一估计。
