# 问题三 V2 阶段4运行预算与恢复协议

## 固定范围

评价期为2025-02-01至2025-12-31，共334天。参数唯一来源为
`outputs/q3_v2/stage3/q3_v2_frozen_config.json`：同星期几负载预测、
历史联合残差情景数\(M=14\)、终端库存价值\(v=0.4\)元/kWh、100 kWh
SOC价值网格，以及0:00、6:00、12:00、18:00更新时点。

策略A每天求解4次版本化情景MILP，预计1336次MILP；策略B仅在0:00
求解共同计划，预计334次MILP，并在其余发布时点刷新历史情景近似未来
价值函数。条件配对消融不再求解MILP。

## 基于阶段3实测的预算

阶段3选定策略1月全月累计MILP时间为452.893 s，120次求解的平均值约
为3.774 s；全月总运行时间471.780 s。以该实测均值线性外推：策略A
MILP时间约84.0 min，策略B的0:00 MILP若按阶段3无调整候选的实测量级
估计约80--90 min。计入365天预测回放缓存、价值函数刷新、逐槽执行、
检查点写入和汇总，顺序运行预期约3--4小时。

45秒是单次MILP时限，不是预计耗时。若每一次均运行至时限，上界约为
20.9小时，另加预测和I/O开销。达到设定gap的求解仅称为“达到设定的
求解精度”，不称理论精确最优。

## 初始化与恢复

策略A和B分别从其阶段3合法1月连续预热轨迹的2025-01-31日末SOC承接为
2025-02-01 0:00 SOC；不使用1月22日评价期日初SOC，也不使用三日功能测试
的6000 kWh初始化。每一个已完成日写入独立日文件及检查点，其中保存下一日
SOC、冻结配置SHA-256和完成日期。恢复时必须同时核对日文件是否连续、配置
哈希是否一致；任一不一致即拒绝恢复，防止重复计费或跳日。

全过程只写入`outputs/q3_v2/stage4/`及`docs/q3_v2/`，不生成或修改
`result3.xlsx`。
